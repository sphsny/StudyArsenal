### Welcome to my COMP1004 coursework.

I developed a SPA (single page application) using HTML, CSS, jQuery and JSON.

#### Functionality:
- Track time in an in-built counter or manually across different subjects
- Name each study session and add notes for each session if desired
- Get an insight of time spent on each subject/session
- Keep track of tasks with a to-do list
- See days left until important events such as deadlines

#### How to use the application:
**Define your subjects in** the **subjects.json** file.
Then, **start a live server from** the **index.html** file.
All further data is stored in the local storage of the browser.
